# Especificación visual V2

- Fondo negro absoluto y exposición ACES inicial `1.1`.
- Horizonte negro, anillo fotónico blanco y disco `#fff200 → #ffb700`.
- Galaxia volumétrica con anillos inclinados, vacíos y clusters; nunca una lámina.
- Título caligráfico crema suspendido por encima del centro, sin bloom quemado.
- Flores botánicas realistas con bordes alfa limpios y escala por profundidad.
- Movimiento lento con inercia; nunca arcade.
- Carta de cristal negro, borde dorado tenue y foco DOM accesible.

Revisar vistas frontal, superior, laterales, baja, móvil vertical, tableta horizontal y escritorio 1920×1080. Todas deben tener foreground, midground y background.
