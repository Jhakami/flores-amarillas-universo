# Decisiones V2

1. Vanilla JS permanece como runtime; React, Laravel y Python no aportan valor al loop WebGL.
2. `OrbitControls` se encapsula en `CameraRig`; pan permanece deshabilitado.
3. Troika dibuja texto espacial SDF y las cartas DOM conservan accesibilidad.
4. Flores se agrupan por variante en `InstancedMesh`; `instanceId` resuelve la carta.
5. El layout usa semillas deterministas.
6. Las densidades bajan progresivamente sin alterar la narrativa.
7. La configuración V1 se respalda y migra una sola vez a V2.
